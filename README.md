# VISORA
A responsive bilingual visual inspiration library prototype for designers.

Features: masonry gallery, search, category/style filters, saved references via localStorage, detail modal, Arabic RTL/English LTR toggle, responsive design.

Open `index.html` in a browser. Images load from Unsplash and require internet access. Before publishing at scale, verify the license and reuse terms for each image. This is a front-end prototype and does not yet include user accounts, cloud sync, or an image database.

Deploy by uploading this folder to a GitHub repository and importing it into a static hosting service such as Vercel.
